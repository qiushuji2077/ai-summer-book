# 门后的光

写给你的 AI 之书。依据《在打开这本书之前》的六条主线，展开为序章与六篇十八章阅读初稿。

## 网站

静态 HTML、CSS 和 JavaScript，无外部运行依赖。入口为 dist/index.html，使用哈希地址定位章节。网站包括全书目录、本篇章节、本章小节、顺序翻阅、当前设备续读、字号、夜读、减少动态与主动开启的轻音乐。

六处教学互动均使用预设内容，不调用模型，不上传用户输入。外部研究资料通过读者主动点击的链接打开。

## 文稿

dist/book.md 是正文与互动文案的唯一编辑母本。修改后运行：

```sh
python scripts/sync-content.py
```

此命令同步 book-data.js，使本地文件打开时也能完整阅读。在线页面会读取 book.md；章节稳定标识不要改动，以保留链接和续读定位。通过 Sites 发布新版本后，线上读者才能看到该版本的修改。

## 资产

封面 doorway.webp 为本项目单次生成的插画。

轻音乐 window-light.mp3 为本项目编写脚本合成的 138 秒无歌词器乐旋律，无外部采样。生成脚本为 scripts/compose_music.py，依赖 NumPy 和 FFmpeg。网页默认静音，读者点击后开始循环，可暂停或调整音量。

## 验证边界

完成静态资源、JavaScript 语法、全篇解析、章节标识、互动选项、文稿同步和音频文件检查。未进行浏览器实屏测试或设备音频试听，不将程序检查表述为真机验证。
