# 门后的光

写给你的 AI 之书。当前为内容深化稿 v0.2：序章与六篇十八章，正文依据提供的完整重写稿，网站呈现依据 `docs/网站内容呈现规格_v0.2.md`。

## 阅读体验

纸白、群青与少量朱红，保留书籍留白。可以按顺序翻阅，通过全书目录跳转，回看本篇章节与本章小节。章尾提供继续阅读、回看与暂停三个主要动作。

六处教学互动围绕接句、上下文、智能体、反例、证据与授权展开。读者先看材料，再选择是否判断、展开解释或直接看全部内容。图解包括遮挡对照、训练与回答、记忆与上下文、同尺度长方形、三层提示、叶片测量、主张与原文对照等。

所有演示使用预设材料，无真实模型调用，不上传读者选择。虚构查证、示例数据与研究介绍分别标明。来源由读者主动打开。

## 文件与维护

| 文件 | 用途 |
| --- | --- |
| `dist/index.html` | 可交互阅读入口，哈希地址定位章节 |
| `dist/book.md` | 正文与六处互动文案的编辑母本、下载文件 |
| `dist/book-data.js` | 从母本生成的内置数据，支持直接打开本地文件 |
| `dist/read.html` | 从同一母本生成的全书静态阅读及打印版，无须脚本 |
| `dist/reader-engine.js` | 段落、表格、结构块与完整后备文本的渲染 |
| `dist/reading-modules.js` | 图解与六处教学互动的结构、状态与操作 |
| `dist/styles.css`、`dist/reading.css` | 基础设计、阅读模块、窄屏、夜读及打印样式 |
| `docs/文稿编辑说明.md` | 文稿格式及编辑流程 |
| `docs/实施与验证_v0.2.md` | 这轮实现与验证范围 |

环境需要 Node.js 18+ 和 Python 3。没有 npm 依赖，也没有客户端构建框架。

```sh
npm run build
npm test
npm run dev
```

也可直接运行 `python scripts/sync-content.py`。它同时更新 `book-data.js` 和 `read.html`，请一起提交。不要单独编辑这两个生成文件。在线互动页使用同次构建的内置数据，不再混用另一次获取的 Markdown。

开发服务器仅用于本地预览，默认端口 4173。`/__qa` 是不进入发布目录的版式检查页，提供不同宽度的 iframe、关闭脚本与旧版续读测试。正式发布只需托管 `dist/`，无需 Node 或 Python 服务。

## 阅读偏好与降级

字号、底色、动效偏好、音量和续读位置仅保存在当前浏览器。旧版像素位置在升级时保留章节并回到章首，提示正文已更新；字体与底色继续保留。没有跨设备同步。

页面默认静态呈现，动画不承担解释；遵循设备减少动态偏好，也可主动关闭动态。音乐默认关闭，切到后台、离开页面或打开外部来源时暂停，回来后不会自动播放。

脚本失败时封面保留完整静态版与文稿入口。未知互动类型或错误的增强配置退回完整文字，不留空白章节。静态版包含所有解释与展开的来源说明；打印样式保留图解和数值。

## 素材

封面 `doorway.webp` 为本项目生成的插画。教学关系图为 SVG/CSS 绘制的示意图，与具体产品的实测结果无关。

轻音乐 `window-light.mp3` 为本项目合成的约 138 秒无歌词器乐旋律，无外部采样。生成脚本 `scripts/compose_music.py` 需要 NumPy 和 FFmpeg；阅读和部署不需要重新生成音频。
