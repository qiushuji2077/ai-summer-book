# 《门后的光》儿童语言润色说明 v0.3

本轮交稿：`book-polished.md`。基于 `/workspace/sites/ai-summer-book/dist/book.md` 内容深化稿 v0.2，完整通读后逐章润色，面向约 10–13 岁读者。交稿包含序章、六篇十八章、全部正文与互动，不是压缩摘要。

## 本轮改动

- **把动作写出来。** “输入形式更丰富”改回照片到来、笔袋移开两次变化；“调用、反馈、调整”连着查资料、拿到结果、改清单来讲。A、B、C 清单现在明确说出：A、B 的名字在材料里能对上，C 的叫法可能指两种植物。
- **术语紧跟已有场景。** token、参数、推理、上下文、记忆、智能体、Harness 的必要解释均保留。“上下文”明确为这次系统实际交给模型的材料，保留系统规则、容量有限、屏幕上的全部聊天未必都在其中，以及材料可能漏用的边界。训练参数与本次对话仍分开。
- **减少抽象连用和成人公文腔。** 将“事实性主张”“一项明确缺口”“实际运行是否可行”等表达，换成当章读者可以直接指出的内容；把一部分连续的否定，改为可以采取的行动。必要的限制和停止要求完整保留。
- **保留思考的难度，降低句子的难度。** 反例、因果判断、引用是否支持结论、权限不能自动延伸等核心关系都保留。长方形尺寸、计算结果与单位未改；正方形属于长方形的说明仍在正文中。
- **改清提示和测量。** 第十一章第二层提示先让读者圈出纸张、跨度相同的记录，再比较橡皮块数；第三层只提供句子起点，不替读者填写实验结果。第十二章当场解释叶片基部、不计叶柄、照片中标尺与叶片的位置关系，以及不同选叶办法怎样影响比较。
- **把比较对象写全。** 第十二章不再笼统说“B 侧有两片较长”，而是明确 B1、B3 与表中三片 A 侧叶片的比较，同时保留 B2 的不同结果。六条数据仍标为编写示例，未变成实测记录，也没有推出光照原因或推广到所有树。
- **让隐私判断更具体。** 第十四章的可提供版本去掉了同学“不太想参加”的心事，仅留下共同整理书的任务相关内容。正文明确：他人材料确需使用时，应向涉及的人确认是否愿意；家长或老师的意见不能代替对方的同意。换名仍可能被认出、检查照片中隐私、只提供所需材料等边界保留。
- **让小作品保持轻巧。** 第十七章不再要求每一步都留认可理由，而是保留重要改动为什么有用；核对时间、地点等关键内容，再就学校信息请负责老师确认可以给哪些人看。第一版、读者意见、重要改动理由和最终版仍保留，完成文件与公开发布仍分开。
- **称呼与来源。** 故事始终面向“你”，其他人以老师、同学、朋友等关系称呼出现，没有新增具名人物。论文链接标题改成论文名，链接地址保留。所有原有研究来源 URL 和核对日期保留；没有把语言润色日期冒充重新查证日期。

## 图解抽取接入位置

所有章节 ID、part、章标题、小节标题与 visual 注释均未改变。以下文字的开头或内容有调整；渲染器若按文字匹配，应以本稿为准。图解需要保留句子的主语、比较对象和限定条件。

### ch07 两个现场

开头仍为 `第一个现场里，` 与 `第二个现场里，`。全文分别为：

> 第一个现场里，门口堆着一摞纸箱，你正愁一个人搬不过来。朋友推门进来：“需要帮忙吗？”你松了一口气，说：“你可真会挑时间。”

> 第二个现场里，你明天就要上台，正抓紧时间排练。朋友却在这时抱来一大箱书，想请你立刻帮忙搬。你看了看钟，又看了看那箱书，说：“你可真会挑时间。”

### ch10 三行判断

引导句现为 `等想法有了变化，你可以留下三行：`。三行全文：

> “原来，我觉得两处的差别主要是树荫造成的。”

> “后来，我发现两处的观察时间也不一样。”

> “现在，我想先让观察时间等条件尽量相同，再来比较。”

开头可分别匹配 `“原来，`、`“后来，`、`“现在，我想`。第三行仍是下一次比较的计划，没有写成已测出的新结论。

### ch11 三层提示

三个加粗层级标签保持原样，正文已调整：

> **第一点提示：**“试两种折法时，两本书之间的距离一样吗？”

> **仍然卡住，再看第二点：**“把纸张相同、两本书间距也相同的记录圈出来。只比较这些记录，哪种折法托住的橡皮更多？”

> **需要表达帮助，再看第三点：**“可以先写‘在这几次、这些条件下……’，填上你看到的结果，再写清楚哪些条件还没有保持一致。”

层级仍为检查条件 → 比较相同条件下的记录 → 帮助表达。它们来自事先编写的示例对话；结果要从读者记录里找，记录不足可以写“目前还不能比较”。请保留层间原有的解释段落，不把三层改为连续代写结论。

### ch14 两个材料版本

第一段开头仍为 `原来的材料是：`：

> 原来的材料是：“某位同学住在哪里，接送时联系家长的电话号码，她这周为什么心情不好……”

第二段开头从 `准备交给工具的版本可以缩成：` 改为 `准备交给工具的版本可以写成：`。该段全文：

> 准备交给工具的版本可以写成：“布置教室时，我和一位同学一起整理了最后一排书。”这件事已经能写进故事，至于对方家住哪里、那天有什么心事，都可以删去。用不上的私密经历，直接拿走，比只换一个名字更稳妥。

用于版本对比的核心句是“布置教室时，我和一位同学一起整理了最后一排书。”其后的删减理由仍属正文内容，不应在抽取时丢失。
