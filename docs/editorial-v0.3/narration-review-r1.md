# 动画字幕与解说脚本审查 R1

对象：`animation-scripts.json`，version 0.3；7 段、35 步。已检查所有 `title`、`caption`、`alt` 及各段 `boundary`。原脚本未修改。

**结论：主体可用，请先修改以下两处，再交复审。** 两处都可通过改句解决，无须重写七段动画。其余建议不阻塞安装。

## 必须修改

### R1-01：矩形尺寸的朗读，要说清两条边和单位

位置：`rectangles.steps[0].caption/alt`、`rectangles.steps[4].caption/alt`（下标从 0 开始）。

当前“一乘九厘米”“四乘四厘米”在静态尺寸标记中可以理解，但作为朗读正文，容易被听成一道乘法题，不能清楚告诉读者两条边各多长。换组处的“二乘三与四乘五”还省去了单位。本段目的正是区分长度与面积，应直接读出边长。

建议改句：

- 第 1 步 caption：**“一个长方形的两条边是一厘米和九厘米。正方形的边长是四厘米。哪个周长大？哪个面积大？”**
- 第 1 步 alt：**“同一厘米比例下，一个长方形的两条边长一厘米和九厘米；另一个正方形的边长四厘米。尚未显示周长和面积的结果。”**
- 第 5 步 caption：**“换成两条边长二厘米、三厘米，和四厘米、五厘米的两个长方形。这次，周长大的那个，面积也大。”**
- 第 5 步 alt：**“两个长方形使用同一厘米比例。第一组边长二厘米、三厘米，周长十厘米，面积六平方厘米；第二组边长四厘米、五厘米，周长十八厘米，面积二十平方厘米。”**

可采用同样清楚的其他表述，不必逐字照抄。图上的 `1×9` 等简短尺寸标记可以保留，但应让每条边的单位和对应关系清楚。

### R1-02：先解释“叶片基部”，再要求读者沿它测量

位置：`leaf.steps[1].caption/alt`。

当前第 1 步只在图和 alt 中标出“叶片基部”，第 2 步就直接要求从它量到叶尖。这个词对目标年龄读者不一定熟悉；有标签也不等于已经解释了位置。caption 还会单独朗读，不能只靠画面补齐。

建议改句：

- 第 2 步 caption：**“这次从叶柄与叶片相接的地方，量到叶尖。这个起点叫叶片基部。叶柄不算在这段长度里。”**
- 第 2 步 alt：**“叶柄与叶片相接的位置标为叶片基部；从这里到叶尖的长度标线亮起。叶柄单独标为不计入本次长度。”**

## 可选的小幅润色

这些不是新的验收门槛；若现稿与相邻正文、实际画面已把意思说明白，可保留。

| 位置 | 建议 | 原因 |
| --- | --- | --- |
| `training.steps[1].caption` | “模型内部能在训练中调整的一些数字，叫参数。” | 比仅说“用于计算的数字”更准确地回扣本步展示的调整。当前简化未造成明显技术错误。 |
| `agent.steps[1].caption` | “A、B 的名称能在资料中对上。C 的叫法却有两种可能，只靠这些材料还定不下来。” | “能和资料对应”稍像工作报告；直接说名称更容易想象。 |
| `leaf.steps[2].caption` | 可在“同一平面”后补“别一个靠前、一个靠后”，并保留不伤害植物的句子。 | 帮助孩子理解为什么标尺不能离镜头更近。不要删去同一平面这个关键关系。 |
| `leaf.steps[3].alt` | “同样长的线段倾斜后，从正面看显得更短；线段本身的长度没有改变。” | 避免 alt 用“参照平面上的投影”增加新的几何术语。caption 当前使用“可能变短”是合适的。 |
| `evidence.steps[1].caption` | 把“第37页”写成“第三十七页”。 | 与周围用于朗读的中文数字保持一致；当前写法本身没有事实错误。 |

若小屏把两个矩形改成上下排列，`rectangles.steps[1–3]` 的“左边、右边”和相关 alt 要同步改为“窄长的那个、正方形”或其他固定称呼。若小屏仍可靠保持左右并列，则无需修改。此项需要结合实际画面确认，不能只据脚本判为已发生的错误。

## 接入时仍需核对的对应关系

本次只审脚本文字，未验收实际动画或语音输出。请在接入时保持各段 boundary 默认可见，并让其随读者使用方式可被访问；不要藏到播放结束或选读栏。初始遮挡状态的整段容器标签、屏幕阅读器文本和隐藏状态也不能提前读出“四支笔”。矩形应实际使用同一厘米比例，字幕中的对象称呼要与当前排列一致。做到这些后，脚本自身未见其他具体阻塞问题。
