# 《门后的光》儿童语言与教学准确性审查基线

审查对象：`/workspace/sites/ai-summer-book/dist/book.md`（内容深化稿 v0.2），并对照《网站内容呈现修改意见与实施规格》v0.2 的正文要求。目标读者：10–13 岁。此文件是给润色者的编辑参考，不是对 v0.3 完整稿的验收结论。

## 复审标准

1. **顺着场景能懂。** 读者能指出发生了什么、哪里出现疑问、补了什么材料、判断怎样改变。关键解释不能只靠另处图解或选读栏补齐。
2. **句子自然，术语有落脚处。** 陌生词就地解释；避免用另一串抽象名词解释前一个名词。保留必要的长短句变化，不把全部正文改成口令或碎句。
3. **平等而不幼稚。** 保留孩子可以理解的复杂性和文学余味；不增加幼儿化称呼、奖励或强制练习。学习建议提供选择，不把每次用工具都变成流程作业。
4. **比喻对应准确。** 工作桌是当前材料，资料柜是可能的外部保存；训练参数与本次对话分开；“看见”“注意力”“幻觉”不暗示人的感受；接话例子不冒充完整模型机制。
5. **结论不越过材料。** 数字、单位和比较对象清楚；“全部”“一定”“原因”须有相应依据。可以保留合理简化和不确定性，不要求不可能的绝对确定。
6. **来源性质紧贴内容。** 真实研究、虚构情境、示例数据和预设互动分清；核心边界默认可见。不能把文案写得像网页实际识别、搜索、发送或付款了。
7. **隐私与许可说得具体。** 只提供任务需要的材料；换名不等于无法识别；自己的决定权不自动覆盖别人。许可须连着当前任务范围，不把所有动作一概判为必须再问或一概允许。
8. **结构和称呼完整。** 序章、六篇十八章及既有 ID、六种互动保留；人物以关系称呼为主；正文及新增字幕不遗留旧人物姓名。研究作者、机构和产品的专名另看来源，不当成旧角色名删除。

复审只把**会具体妨碍理解、造成错误认识、丢失必要边界或破坏内容完整性**的问题列为阻塞项。纯粹偏好、同样通顺的另一种写法和不必要的追求完美，不阻止安装。

## 最值得优先处理的九处语言问题

| 位置 | 当前表达或现象 | 对读者的影响 | 修改方向 |
| --- | --- | --- | --- |
| ch03 章末停顿 | “少说了哪些话，也就多保留了哪些真实？” | 修辞的意思需要再猜一次，反而遮住了本章清楚的证据比较。 | 直接问第二个标题没有作出什么承诺，为什么现在还不能说已经解决污染。保留前面的两标题比较。 |
| ch04 训练解释 | “表现有差距”“形成完成某些任务的能力”“后续训练还会进一步影响……”连在一起 | 孩子虽认识每个字，却不容易指出到底比较了什么、改变了什么。 | 让“预测的后文—材料中的后文—计算差别—调整数字”保持可追踪关系；概括能力的句子可以更短。不要增添错误的“记住所有训练答案”说法。 |
| ch05 术语定义 | “整体材料”“经系统组织的信息”接连出现 | 工作桌已经建立的具体印象被再次抽象化；容易把上下文等同于屏幕上可见的聊天。 | 用“这次回答时，系统实际交给模型使用的材料”回扣桌面，再列少量例子。保留系统规则和并非全部聊天都在其中的边界。 |
| ch06 工作记录 | 多次出现“A、B 可以对应”“C 的名称有歧义”“一项明确缺口” | 像成人工作报告，读者不易想象清单究竟哪里没填好。 | 说清“A、B 的名字在材料中能对上；C 的叫法可能指不同植物，所以名字还不能填定”。不必给植物编真实名称，也不需要增加新情节。 |
| ch11 第二层提示 | “你能确认的结果，适用于这些尝试中的哪一部分？” | 这本来是帮助卡住的读者，句子本身却仍要求理解“结果适用范围”的抽象关系。 | 先让读者圈出纸张、两本书间距等条件相同的记录，再问这些记录允许自己怎么说。第三层继续给表达起点，不替读者编实验结果。 |
| ch12 测量方法 | “叶片基部”“同一平面”“选择差异”首次出现较密 | 实际要做什么不够一眼明白，核心方法不能全等着配图解释。 | 基部可就地说成叶柄与叶片相接的位置；解释标尺为什么要靠近叶片所在的平面；把“选择差异”说成“一边专挑大叶，一边随手挑，结果就可能是挑法造成的”。 |
| ch12 结论 | “B 侧有两片叶片较长” | “较长”缺少明确比较对象，削弱本章正在教的准确表达。 | 紧贴这六条示例记录，明确 B1、B3 比表中的三片 A 侧叶片都长，B2 没有；不推广成 B 侧的叶片普遍更长，更不推出光照原因。 |
| ch14 隐私 | “先问老师或家长，并考虑涉及的人是否同意” | “考虑”听起来可以只是想一下；读者也可能误以为老师或家长的意见自动代替材料主人的同意。 | 对照片、日记等涉及他人的私密材料，明确先删去不需要的内容；确需使用时，应与涉及的人确认是否愿意，并在拿不准时请可信任的大人帮助判断。不要写成无关信息只要同意就应上传。 |
| ch17 作品过程 | “每一步都保留你认可的理由”“一旦内容全部核实、达到发布条件”“有相应权限的人” | 多句相邻像成人审稿验收要求，容易让一页小作品变成处处要留证明的任务；“全部核实”也容易被读成无法完成的绝对要求。 | 聚焦重要改动为什么有用，以及时间、地点等关键事实是否核对；具体说明涉及学校安排时由谁确认发布对象。保留草稿、最终版及必要授权，不必要求每个小改动都单独留理由。 |

以上为优先编辑点，并非要求逐条照抄建议。若完整稿采用其他同样清楚、准确的写法，可直接通过。

## 后续完整稿及动画字幕复审

收到明确待审文件后，检查整稿和字幕是否相互一致。字幕尤其检查：单屏是否能自然读完；主语和比较对象是否省丢；步骤是否真有先后与反馈；字幕不把教学演示称为实时模型行为；示例数字、单位、研究限制与行动授权是否随画面一起保留。若发现具体阻塞项，将逐条指出位置、问题与最小修改方向；修改后只复核变更及受影响关系。
