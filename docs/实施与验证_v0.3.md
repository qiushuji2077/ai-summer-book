## 儿童语言编辑

以已接入的 v0.2 完整稿为基线。一个儿童语言编辑代理完整通读并润色序章与十八章；另一个审查代理独立逐段阅读、核对结构和数据，主代理负责最终接入。

第一轮完整复审发现一处必修：第三章把酶泛称为蛋白质，应限定为本章研究的酶。编辑已定位修改，并顺手把第十四章“号码接送”的措辞改为明确的电话号码。两行以外的已审正文保持不变。复审记录与最终文本校验值见 `editorial-v0.3/review-r2.md`。

主要改动包括就地解释 token、参数、上下文和叶片基部；把三层提示改为可执行的检查与比较；写清 B1/B3 与三片 A 侧叶片的比较对象；区分他人的同意与老师家长的帮助；减轻小作品流程中的成人验收口吻。稿件没有缩写成摘要，章节标记、六类互动、18 条图解标记、18 条选项配置、14 个来源地址和原有示例数字均保留。网站称呼仍为“你”。

科学表述的定位核对参考 [Thomas R. Cech 在 NobelPrize.org 的说明](https://www.nobelprize.org/prizes/chemistry/1989/cech/article/?print=1)：RNA 也能催化反应，因此正文把蛋白质的说法限定在本章酶研究对象，不向儿童段落额外加入术语。其余具名研究资料已在同日的 v0.2 接入阶段核对，本轮保留原有事实范围和来源日期。

全部为本地绘制的 SVG/HTML 教学动画，没有运行真实模型或识别图片。字幕、可选朗读与静态分镜来自 `content/animation-scripts.json`。脚本由独立审查代理两轮核对，第一轮的边长单位和叶片基部两项问题已修订，第二轮通过。

播放器默认停止。读者可播放、暂停、前后逐步观看、跳到任一步、从头看或展开完整分镜。每步只播放一次变化，章节结束不循环。暂停后继续会从当前一步重新呈现，字幕停留时长按长度安排；有声音时等当前解说结束后再前进。

语音使用 Web Speech API 的设备中文声音，优先本地声音，不包含录制配音。没有可用中文声音、朗读出错或结束事件迟迟未返回时提供字幕后备。参考 [SpeechSynthesis](https://developer.mozilla.org/en-US/docs/Web/API/SpeechSynthesis) 与 [getVoices](https://developer.mozilla.org/en-US/docs/Web/API/SpeechSynthesis/getVoices)。

开启减少动态后仅手动换图；语音可以只读当前图，结束后不自动前进。遵循设备的 [减少动态偏好](https://developer.mozilla.org/en-US/docs/Web/CSS/@media/prefers-reduced-motion)。开启解说暂停背景音乐，主动开启音乐也暂停图解；离开章节、图解完全离开视窗、打开目录或设置、切到后台、页面离开时暂停图解。回来后不自动恢复。

## 同步与修复

正文母本、下载稿、内置数据与静态版保持一次构建同步；另生成独立动画解说 Markdown。第十一章提示抽取改为第一层提示到 V11 标记之间的段落，不再依赖解释句的固定开头。

修复字号与底色事件选择器误选 `body` 的问题：原先页面点击会重复套用设置，可能将正在切换的减少动态复选框改回旧值。现在仅绑定对应设置按钮，网页减少动态开关可正常开启和取消。

## 验证边界

浏览器检查使用同一浏览器中的不同宽度 iframe，不等同于多台真机。文字 200% 是根字号放大，不等同于整个浏览器的真实缩放。系统级减少动态依据实现与样式核对，网页开关已实际操作。此浏览器未提供中文声音，因此实际验证的是字幕降级；中文朗读的声音质量、不同设备与后台策略仍取决于设备。未进行真实儿童试读、屏幕阅读器或纸张打印实测。
